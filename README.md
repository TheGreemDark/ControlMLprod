# ControlMLprod

Учебный проект по дисциплине
«Управление продуктами искусственного интеллекта на разных этапах жизненного цикла».

## Требования

- Python 3.13
- uv
- Git
- Unix / macOS / Linux / WSL
- make

## Установка и запуск

### Клонирование репозитория:

```bash
git clone https://github.com/TheGreemDark/ControlMLprod.git
```
```bash
cd ControlMLprod
```

### Установка
```bash
make setup
```

### Проверка
```bash
make check
```
